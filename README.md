# Healthcare Analytics Project

## 📌 Project Overview

This project focuses on analyzing healthcare data to identify key trends, patient insights, and important performance metrics.

The analysis was performed using data cleaning, data analysis, and visualization techniques to transform raw healthcare data into meaningful insights.

## 🛠️ Tools & Technologies

* Microsoft Excel
* SQL
* Data Analysis
* Data Visualization

## 📊 Key Analysis

* Patient and healthcare data analysis
* Identification of important trends and patterns
* KPI analysis
* Data cleaning and validation
* Interactive dashboards and visualizations
* Generation of meaningful business insights

## 🎯 Project Objective

The main objective of this project is to analyze healthcare data and present the results in an easy-to-understand dashboard that can support data-driven decision-making.

## 📁 Project Files

This repository contains the files related to the Healthcare Analytics project, including the dataset, analysis files, and dashboard.
